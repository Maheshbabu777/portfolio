# **Portfolio Website**

This is a **personal portfolio website** designed using **HTML,CSS and JS**. It includes sections such as an **About , Educational Details, and Contact Me**.

## **Features**

- **Responsive design**
- **Navigation bar** for easy access to sections
- **Contact**
- **Styled using CSS** for a modern look

## **Technologies Used**

- **HTML**
- **CSS**
- **JS**

## **How to Use**

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Mahesh777/portfolio.git
   ```
2. **Navigate to the project folder:**
   ```sh
   cd portfolio
   ```
3. **Open `index.html` in a web browser.**

## **Folder Structure**



├── **index.html**
├── **style.css**
├── **responsive.css**
└── **assets/**
    ├── **images/**


## **Customization**

- Modify **`index.html`** and other **HTML** files to update content.
- Update **`style.css`** to change styles and colors.
- Replace images in the **`assets/images/`** folder with your own.
